4.1 ¿Qué es la Herencia?

La herencia es un mecanismo que permite crear nuevas clases basadas en clases existentes, reutilizando y extendiendo su funcionalidad.

4.1.1 Analogía del mundo real

Piensa en la clasificación de animales:

  • Todos los animales tienen características comunes: nacen, crecen, se reproducen
  • Los mamíferos heredan esas características y agregan las suyas: tienen pelo, amamantan
  • Los perros heredan de mamíferos y agregan: ladran, tienen razas específicas
Animal (clase padre/base)
  ↓
Mamífero (clase hija/derivada)
  ↓
Perro (clase hija/derivada)

4.2 Tu Primera Herencia

4.2.1 Ventajas de la Herencia

  1. Reutilización de código: No necesitas reescribir código común
  2. Organización lógica: Refleja relaciones del mundo real
  3. Facilita mantenimiento: Cambios en la clase padre afectan a todas las hijas
  4. Extensibilidad: Puedes agregar funcionalidad sin modificar el código original

4.3 Múltiples Clases Hijas

class Animal:
    def __init__(self, nombre):
        self.nombre = nombre
    
    def hacer_sonido(self):
        print(f"{self.nombre} hace un sonido")

# Diferentes clases heredan de Animal
class Perro(Animal):
    def hacer_sonido(self):
        print(f"{self.nombre} dice: ¡Guau guau!")

class Gato(Animal):
    def hacer_sonido(self):
        print(f"{self.nombre} dice: ¡Miau!")

class Vaca(Animal):
    def hacer_sonido(self):
        print(f"{self.nombre} dice: ¡Muuu!")

# Crear diferentes animales
perro = Perro("Rex")
gato = Gato("Whiskers")
vaca = Vaca("Lola")

# Todos tienen el mismo método, pero con comportamiento diferente
perro.hacer_sonido()
gato.hacer_sonido()
vaca.hacer_sonido()
Rex dice: ¡Guau guau!
Whiskers dice: ¡Miau!
Lola dice: ¡Muuu!

4.4 Extendiendo el Constructor con super()

super() permite llamar a métodos de la clase padre, especialmente útil con constructores:

4.4.1 ¿Por qué usar super()?

  1. Evita duplicación: No repites código del constructor padre
  2. Mantenibilidad: Si cambias la clase padre, no necesitas cambiar las hijas
  3. Herencia múltiple: Funciona correctamente con herencia múltiple

4.5 Sobrescritura de Métodos (Override)

Las clases hijas pueden redefinir métodos de la clase padre:

class Empleado:
    def __init__(self, nombre, salario_base):
        self.nombre = nombre
        self.salario_base = salario_base
    
    def calcular_salario(self):
        return self.salario_base
    
    def info(self):
        print(f"Empleado: {self.nombre}")
        print(f"Salario: ${self.calcular_salario()}")

class Gerente(Empleado):
    def __init__(self, nombre, salario_base, bono):
        super().__init__(nombre, salario_base)
        self.bono = bono
    
    # Sobrescribir método de la clase padre
    def calcular_salario(self):
        return self.salario_base + self.bono

class Vendedor(Empleado):
    def __init__(self, nombre, salario_base, comision_ventas, ventas):
        super().__init__(nombre, salario_base)
        self.comision_ventas = comision_ventas
        self.ventas = ventas
    
    # Sobrescribir método de la clase padre
    def calcular_salario(self):
        return self.salario_base + (self.ventas * self.comision_ventas)

# Crear diferentes tipos de empleados
empleado = Empleado("Juan", 10000)
gerente = Gerente("Ana", 15000, 5000)
vendedor = Vendedor("Carlos", 8000, 0.05, 100000)

# Todos usan info() pero con diferentes cálculos de salario
empleado.info()
print("-" * 30)
gerente.info()
print("-" * 30)
vendedor.info()
Empleado: Juan
Salario: $10000
------------------------------
Empleado: Ana
Salario: $20000
------------------------------
Empleado: Carlos
Salario: $13000.0

4.6 Herencia Multinivel

4.6.1 ¿Cómo encuentra Python un método?

Cuando llamas mi_perro.respirar(), Python busca respirar primero en la clase del objeto (Perro) y, si no lo encuentra, sube por la jerarquía en el orden que indica Perro.__mro__ (Method Resolution Order). Pulsa los botones para verlo, incluido el caso de un método que no existe y la cadena de super().__init__() del constructor.

object(clase base de todo)
▲ hereda de
SerVivo__init__(nombre)
respirar()
▲ hereda de
Animal__init__(nombre, especie)
moverse()
▲ hereda de
Perro__init__(nombre, raza)
ladrar()
Elige una llamada para ver cómo Python busca el método.

Puedes consultar ese orden directamente:

# La misma jerarquía de la herencia multinivel (sin el contenido de los métodos)
class SerVivo: pass
class Animal(SerVivo): pass
class Perro(Animal): pass

print([clase.__name__ for clase in Perro.__mro__])
['Perro', 'Animal', 'SerVivo', 'object']

4.7 isinstance() e issubclass()

Funciones útiles para verificar relaciones de herencia:

class Animal:
    pass

class Perro(Animal):
    pass

class Gato(Animal):
    pass

mi_perro = Perro()
mi_gato = Gato()

# isinstance() - verifica si un objeto es instancia de una clase
print("isinstance() - Verificar objetos:")
print(f"mi_perro es instancia de Perro: {isinstance(mi_perro, Perro)}")
print(f"mi_perro es instancia de Animal: {isinstance(mi_perro, Animal)}")
print(f"mi_perro es instancia de Gato: {isinstance(mi_perro, Gato)}")
print()

# issubclass() - verifica si una clase es subclase de otra
print("issubclass() - Verificar clases:")
print(f"Perro es subclase de Animal: {issubclass(Perro, Animal)}")
print(f"Gato es subclase de Animal: {issubclass(Gato, Animal)}")
print(f"Perro es subclase de Gato: {issubclass(Perro, Gato)}")
print(f"Animal es subclase de Perro: {issubclass(Animal, Perro)}")
isinstance() - Verificar objetos:
mi_perro es instancia de Perro: True
mi_perro es instancia de Animal: True
mi_perro es instancia de Gato: False

issubclass() - Verificar clases:
Perro es subclase de Animal: True
Gato es subclase de Animal: True
Perro es subclase de Gato: False
Animal es subclase de Perro: False

4.8 Ejemplo Completo: Sistema de Formas Geométricas

import math

class Forma:
    """Clase base para todas las formas geométricas"""
    def __init__(self, color="Negro"):
        self.color = color
    
    def area(self):
        raise NotImplementedError("Las subclases deben implementar este método")
    
    def perimetro(self):
        raise NotImplementedError("Las subclases deben implementar este método")
    
    def descripcion(self):
        return f"Soy una forma de color {self.color}"

class Rectangulo(Forma):
    def __init__(self, ancho, alto, color="Negro"):
        super().__init__(color)
        self.ancho = ancho
        self.alto = alto
    
    def area(self):
        return self.ancho * self.alto
    
    def perimetro(self):
        return 2 * (self.ancho + self.alto)
    
    def descripcion(self):
        return f"Rectángulo {self.color} de {self.ancho}x{self.alto}"

class Circulo(Forma):
    def __init__(self, radio, color="Negro"):
        super().__init__(color)
        self.radio = radio
    
    def area(self):
        return math.pi * self.radio ** 2
    
    def perimetro(self):
        return 2 * math.pi * self.radio
    
    def descripcion(self):
        return f"Círculo {self.color} con radio {self.radio}"

class Cuadrado(Rectangulo):  # Hereda de Rectangulo
    def __init__(self, lado, color="Negro"):
        # Un cuadrado es un rectángulo con ancho = alto
        super().__init__(lado, lado, color)
    
    def descripcion(self):
        return f"Cuadrado {self.color} de lado {self.ancho}"

# Función que funciona con cualquier forma
def mostrar_info_forma(forma):
    print(forma.descripcion())
    print(f"  Área: {forma.area():.2f}")
    print(f"  Perímetro: {forma.perimetro():.2f}")
    print("-" * 40)

# Crear diferentes formas
rectangulo = Rectangulo(5, 10, "Rojo")
circulo = Circulo(7, "Azul")
cuadrado = Cuadrado(6, "Verde")

# Mostrar información de todas
formas = [rectangulo, circulo, cuadrado]
for forma in formas:
    mostrar_info_forma(forma)

  Área: 50.00
  Perímetro: 30.00
----------------------------------------
Círculo Azul con radio 7
  Área: 153.94
  Perímetro: 43.98
----------------------------------------
Cuadrado Verde de lado 6
  Área: 36.00
  Perímetro: 24.00

4.9.2 Ejercicio 2: Sistema de Cuentas Bancarias

Crea:

  • Clase base CuentaBancaria con: titular, saldo, métodos depositar(), retirar(), consultar_saldo()
  • Clase CuentaAhorro que hereda y agrega: tasa_interes, método aplicar_interes()
  • Clase CuentaCorriente que hereda y agrega: limite_sobregiro, modifica retirar() para permitir sobregiro

Prueba todas las funcionalidades.

TipSolución del ejercicio 2 
class CuentaBancaria:
    def __init__(self, titular, saldo=0):
        self.titular = titular
        self.saldo = saldo

    def depositar(self, cantidad):
        self.saldo += cantidad

    def retirar(self, cantidad):
        if cantidad > self.saldo:
            print(f"  Fondos insuficientes para retirar ${cantidad}")
            return False
        self.saldo -= cantidad
        return True

    def consultar_saldo(self):
        print(f"  {self.titular}: saldo ${self.saldo:,.2f}")
        return self.saldo

class CuentaAhorro(CuentaBancaria):
    def __init__(self, titular, saldo=0, tasa_interes=0.05):
        super().__init__(titular, saldo)
        self.tasa_interes = tasa_interes

    def aplicar_interes(self):
        self.saldo += self.saldo * self.tasa_interes

class CuentaCorriente(CuentaBancaria):
    def __init__(self, titular, saldo=0, limite_sobregiro=1000):
        super().__init__(titular, saldo)
        self.limite_sobregiro = limite_sobregiro

    def retirar(self, cantidad):  # Sobrescribe: permite saldo negativo hasta el límite
        if cantidad > self.saldo + self.limite_sobregiro:
            print(f"  Excede el sobregiro permitido (${self.limite_sobregiro})")
            return False
        self.saldo -= cantidad
        return True

print("Cuenta de ahorro:")
ahorro = CuentaAhorro("Ana", 10000, 0.03)
ahorro.retirar(20000)
ahorro.aplicar_interes()
ahorro.consultar_saldo()

print("Cuenta corriente:")
corriente = CuentaCorriente("Luis", 500, limite_sobregiro=1000)
corriente.retirar(1200)   # Queda en -700: permitido
corriente.consultar_saldo()
corriente.retirar(500)    # Excede el límite

  Fondos insuficientes para retirar $20000
  Ana: saldo $10,300.00
Cuenta corriente:
  Luis: saldo $-700.00
  Excede el sobregiro permitido ($1000)

4.9.3 Ejercicio 3: Herencia Multinivel - Universidad

Crea una jerarquía de 3 niveles:

  1. Persona: nombre, edad, método presentarse()
  2. Estudiante (hereda de Persona): agrega matricula, carrera, calificaciones (lista), método agregar_calificacion()
  3. EstudianteInternacional (hereda de Estudiante): agrega pais_origen, requiere_visa (bool), método info_visa()

Crea un objeto de EstudianteInternacional y verifica que tiene acceso a todos los métodos.

TipSolución del ejercicio 3 
class Persona:
    def __init__(self, nombre, edad):
        self.nombre = nombre
        self.edad = edad

    def presentarse(self):
        print(f"Hola, soy {self.nombre} y tengo {self.edad} años")

class Estudiante(Persona):
    def __init__(self, nombre, edad, matricula, carrera):
        super().__init__(nombre, edad)
        self.matricula = matricula
        self.carrera = carrera
        self.calificaciones = []

    def agregar_calificacion(self, calificacion):
        self.calificaciones.append(calificacion)

class EstudianteInternacional(Estudiante):
    def __init__(self, nombre, edad, matricula, carrera, pais_origen, requiere_visa):
        super().__init__(nombre, edad, matricula, carrera)
        self.pais_origen = pais_origen
        self.requiere_visa = requiere_visa

    def info_visa(self):
        estado = "requiere visa" if self.requiere_visa else "no requiere visa"
        print(f"{self.nombre} viene de {self.pais_origen} y {estado}")

ei.presentarse()                 # De Persona
ei.agregar_calificacion(9.5)     # De Estudiante
ei.info_visa()                   # Propio
print("Calificaciones:", ei.calificaciones)
print("¿Es Persona?", isinstance(ei, Persona))

4.9.4 Ejercicio 4: Sistema de Productos (Desafío)

Crea un sistema de productos con herencia:

  1. Clase base Producto:
    • Atributos: nombre, precio_base, stock
    • Métodos: calcular_precio_final(), info(), reducir_stock(cantidad)
  2. Clase ProductoElectronico (hereda de Producto):
    • Agrega: garantia_meses, marca
    • Sobrescribe calcular_precio_final(): agrega 10% de impuesto
  3. Clase ProductoAlimenticio (hereda de Producto):
    • Agrega: fecha_caducidad
    • Sobrescribe calcular_precio_final(): si está próximo a caducar (tu decides el criterio), aplica 30% de descuento
  4. Crea una función procesar_compra(producto, cantidad) que:
    • Verifique si hay stock suficiente
    • Muestre el precio final
    • Reduzca el stock
    • Funcione con cualquier tipo de producto

Prueba con varios productos diferentes.

TipSolución del ejercicio 4 
from datetime import date, timedelta

class Producto:
    def __init__(self, nombre, precio_base, stock):
        self.nombre = nombre
        self.precio_base = precio_base
        self.stock = stock

    def calcular_precio_final(self):
        return self.precio_base

    def reducir_stock(self, cantidad):
        self.stock -= cantidad

    def info(self):
        print(f"{self.nombre}: ${self.calcular_precio_final():.2f} (stock {self.stock})")

class ProductoElectronico(Producto):
    def __init__(self, nombre, precio_base, stock, garantia_meses, marca):
        super().__init__(nombre, precio_base, stock)
        self.garantia_meses = garantia_meses
        self.marca = marca

    def calcular_precio_final(self):
        return self.precio_base * 1.10  # +10% de impuesto

class ProductoAlimenticio(Producto):
    DIAS_PROXIMO_A_CADUCAR = 5  # Criterio elegido

    def __init__(self, nombre, precio_base, stock, fecha_caducidad):
        super().__init__(nombre, precio_base, stock)
        self.fecha_caducidad = fecha_caducidad

    def calcular_precio_final(self):
        dias = (self.fecha_caducidad - date.today()).days
        if dias <= self.DIAS_PROXIMO_A_CADUCAR:
            return self.precio_base * 0.70  # 30% de descuento
        return self.precio_base

def procesar_compra(producto, cantidad):
    """Funciona con cualquier subclase de Producto."""
    if cantidad > producto.stock:
        print(f"✗ Stock insuficiente de {producto.nombre} (hay {producto.stock})")
        return
    total = producto.calcular_precio_final() * cantidad
    producto.reducir_stock(cantidad)
    print(f"✓ {cantidad} x {producto.nombre} = ${total:.2f}")

audifonos = ProductoElectronico("Audífonos", 1000, 5, 12, "Sony")
yogur = ProductoAlimenticio("Yogur", 20, 30, date.today() + timedelta(days=2))
arroz = ProductoAlimenticio("Arroz", 35, 50, date.today() + timedelta(days=200))

for producto, cantidad in [(audifonos, 2), (yogur, 10), (arroz, 3), (audifonos, 10)]:
    procesar_compra(producto, cantidad)
✓ 2 x Audífonos = $2200.00
✓ 10 x Yogur = $140.00
✓ 3 x Arroz = $105.00
✗ Stock insuficiente de Audífonos (hay 3)
