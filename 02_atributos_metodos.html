2.1 ¿Qué son los Métodos?

Si los atributos son las características de un objeto (lo que es), los métodos son las acciones que puede realizar (lo que hace).

2.1.1 Analogía del mundo real

Piensa en un teléfono móvil:

  • Atributos: marca, modelo, color, nivel de batería
  • Métodos: hacer_llamada(), enviar_mensaje(), tomar_foto(), reproducir_musica()

2.2 Tu Primer Método

Vamos a crear una clase con métodos:

class Perro:
    # Atributo de clase
    especie = "Canis familiaris"
    
    # Método (función dentro de una clase)
    def ladrar(self):
        print("¡Guau guau!")
    
    def comer(self):
        print("Ñam ñam... comiendo croquetas")

# Crear un objeto
mi_perro = Perro()

# Llamar a los métodos
mi_perro.ladrar()
mi_perro.comer()
¡Guau guau!
Ñam ñam... comiendo croquetas

2.2.1 ¿Qué es self?

self es una referencia al objeto actual. Es como decir “yo mismo” o “este objeto específico”.

Importante:

  • self SIEMPRE es el primer parámetro de un método de instancia
  • Python lo pasa automáticamente, NO necesitas escribirlo al llamar al método
  • Puedes usar cualquier nombre, pero por convención usamos self

2.2.2 self en acción

Avanza paso a paso y fíjate en el marco de incrementar: en la primera llamada self apunta a a y en la segunda apunta a b. El método es el mismo; cambia el objeto al que se aplica.

2.3 Métodos que Usan Atributos

class Perro:
    def ladrar(self):
        print("¡Guau guau!")
    
    def presentarse(self):
        # Acceder a atributos del objeto usando self
        print(f"Hola, soy {self.nombre} y tengo {self.edad} años")

# Crear objeto y asignar atributos
mi_perro = Perro()
mi_perro.nombre = "Max"
mi_perro.edad = 3

# Llamar al método
mi_perro.presentarse()
mi_perro.ladrar()

2.5 Métodos que Modifican Atributos

Los métodos pueden cambiar los atributos del objeto:

class CuentaBancaria:
    def depositar(self, cantidad):
        self.saldo += cantidad
        print(f"Depósito exitoso. Nuevo saldo: ${self.saldo}")
    
    def retirar(self, cantidad):
        if cantidad <= self.saldo:
            self.saldo -= cantidad
            print(f"Retiro exitoso. Nuevo saldo: ${self.saldo}")
        else:
            print("Fondos insuficientes")
    
    def consultar_saldo(self):
        print(f"Saldo actual: ${self.saldo}")
        return self.saldo

# Crear cuenta
mi_cuenta = CuentaBancaria()
mi_cuenta.titular = "Ana García"
mi_cuenta.saldo = 1000

# Operaciones
mi_cuenta.consultar_saldo()
mi_cuenta.depositar(500)
mi_cuenta.retirar(200)
mi_cuenta.retirar(2000)  # Más de lo que tiene

class Libro:
    def prestar(self):
        if self.disponible:
            self.disponible = False
            print(f"'{self.titulo}' ha sido prestado")
        else:
            print(f"'{self.titulo}' no está disponible")
    
    def devolver(self):
        self.disponible = True
        print(f"'{self.titulo}' ha sido devuelto")
    
    def info(self):
        estado = "Disponible" if self.disponible else "Prestado"
        print(f"Título: {self.titulo}")
        print(f"Autor: {self.autor}")
        print(f"Estado: {estado}")
        print("-" * 30)

  • Métodos:

TipSolución del ejercicio 1 
class Rectangulo:
    def calcular_area(self):
        return self.ancho * self.alto

    def calcular_perimetro(self):
        return 2 * (self.ancho + self.alto)

    def es_cuadrado(self):
        return self.ancho == self.alto

rect = Rectangulo()
rect.ancho = 5
rect.alto = 10

print(rect.calcular_area())       # 50
print(rect.calcular_perimetro())  # 30
print(rect.es_cuadrado())         # False

2.9.2 Ejercicio 2: Clase Termometro

Crea una clase Termometro con:

  • Atributo: temperatura_celsius
  • Métodos:
    • a_fahrenheit(): retorna temperatura en Fahrenheit (F = C × 9/5 + 32)
    • a_kelvin(): retorna temperatura en Kelvin (K = C + 273.15)
    • estado(): retorna “Congelando” si < 0, “Normal” si 0-30, “Calor” si > 30
TipSolución del ejercicio 2 
class Termometro:
    def a_fahrenheit(self):
        return self.temperatura_celsius * 9 / 5 + 32

    def a_kelvin(self):
        return self.temperatura_celsius + 273.15

    def estado(self):
        if self.temperatura_celsius < 0:
            return "Congelando"
        elif self.temperatura_celsius <= 30:
            return "Normal"
        else:
            return "Calor"

t = Termometro()
for c in [-5, 22, 38]:
    t.temperatura_celsius = c
    print(f"{c}°C = {t.a_fahrenheit():.1f}°F = {t.a_kelvin():.2f}K -> {t.estado()}")
-5°C = 23.0°F = 268.15K -> Congelando
22°C = 71.6°F = 295.15K -> Normal
38°C = 100.4°F = 311.15K -> Calor

2.9.3 Ejercicio 3: Clase CarritoCompras

Crea una clase CarritoCompras con:

  • Atributo: total (inicializado en 0)
  • Métodos:
    • agregar_producto(nombre, precio): suma el precio al total e imprime mensaje
    • aplicar_descuento(porcentaje): reduce el total por el porcentaje
    • ver_total(): muestra el total actual
    • pagar(): imprime recibo y resetea total a 0
TipSolución del ejercicio 3 
class CarritoCompras:
    total = 0  # Valor inicial; el primer `self.total += ...` crea el atributo de instancia

    def agregar_producto(self, nombre, precio):
        self.total += precio
        print(f"Agregado: {nombre} (${precio:.2f})")

    def aplicar_descuento(self, porcentaje):
        self.total -= self.total * porcentaje / 100
        print(f"Descuento del {porcentaje}% aplicado")

    def ver_total(self):
        print(f"Total actual: ${self.total:.2f}")

    def pagar(self):
        print("=" * 25)
        print(f"RECIBO  Total pagado: ${self.total:.2f}")
        print("=" * 25)
        self.total = 0

carrito = CarritoCompras()
carrito.agregar_producto("Libro", 350)
carrito.agregar_producto("Café", 80)
carrito.ver_total()
carrito.aplicar_descuento(10)
carrito.ver_total()
carrito.pagar()
carrito.ver_total()

2.9.4 Ejercicio 4: Clase Mascota (Desafío)

Crea una clase Mascota con:

  • Atributos: nombre, hambre (0-100), felicidad (0-100), energia (0-100)
  • Métodos:
    • alimentar(): reduce hambre en 30, aumenta energia en 10
    • jugar(): aumenta felicidad en 20, aumenta hambre en 10, reduce energia en 15
    • dormir(): restaura energia a 100, reduce hambre en 5
    • estado(): muestra todos los atributos
    • esta_bien(): retorna True si hambre < 70, felicidad > 30 y energia > 20

Asegúrate de que los valores nunca sean negativos ni mayores a 100.

TipSolución del ejercicio 4 
class Mascota:
    def _limitar(self, valor):
        """Mantiene un valor entre 0 y 100."""
        return max(0, min(100, valor))

    def alimentar(self):
        self.hambre = self._limitar(self.hambre - 30)
        self.energia = self._limitar(self.energia + 10)

    def jugar(self):
        self.felicidad = self._limitar(self.felicidad + 20)
        self.hambre = self._limitar(self.hambre + 10)
        self.energia = self._limitar(self.energia - 15)

    def dormir(self):
        self.energia = 100
        self.hambre = self._limitar(self.hambre - 5)

    def estado(self):
        print(f"{self.nombre}: hambre={self.hambre}, "
              f"felicidad={self.felicidad}, energía={self.energia}")

    def esta_bien(self):
        return self.hambre < 70 and self.felicidad > 30 and self.energia > 20

mascota = Mascota()
mascota.nombre = "Firulais"
mascota.hambre = 60
mascota.felicidad = 20
mascota.energia = 40

mascota.estado()
print("¿Está bien?", mascota.esta_bien())
mascota.jugar()
mascota.jugar()
mascota.alimentar()
mascota.estado()
print("¿Está bien?", mascota.esta_bien())
mascota.dormir()
mascota.estado()

¿Está bien? False
Firulais: hambre=50, felicidad=60, energía=20
¿Está bien? False
